# GitHub 基础概念

## Repository

Repository 是仓库，用来保存一个项目的文件、说明和修改历史。

## README

README 是项目说明文件，别人打开仓库后通常最先看到它。

## Commit

Commit 是一次有说明的修改记录。

## Issue

Issue 是任务、问题或改进建议，可以用来管理项目中的待办事项。

## Branch

Branch 是分支，可以在不影响主线的情况下独立修改内容。

## Pull Request

Pull Request 是提交修改并请求合并的流程，可以用来检查、讨论和合并修改。

## Merge

Merge 是合并，把一个分支或 Pull Request 里的修改合并到目标分支。

## GitHub Pages

GitHub Pages 可以把仓库中的静态网页发布成公开网站。
