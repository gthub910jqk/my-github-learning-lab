# My GitHub Learning Lab

这是我用 21 天学习 GitHub 的作品仓库。

## 项目目标

- 学会创建和管理 GitHub 仓库
- 学会使用 Markdown 写项目文档
- 学会使用 Issue、Branch 和 Pull Request
- 使用 GitHub Pages 发布一个简单网站

## 21 天学习计划

- [x] 第 1 阶段：建立认知地图
- [ ] 第 2 阶段：掌握基础操作
- [ ] 第 3 阶段：模仿协作流程
- [ ] 第 4 阶段：独立完成作品
- [ ] 第 5 阶段：反馈复盘升级

## 最终作品

一个公开的 GitHub 仓库和一个 GitHub Pages 网站。
